# 版本记录

文中 `artifacts/` 路径指本地构建或验收产物。从源码生成安装包的步骤见[开发手册](DEVELOPMENT.md#14-发布与升级流程)。

本记录根据现有源码、对话确认的交付范围、历史安装包和验证报告整理。早期版本没有独立的完整发布日志，未补写无法确认的发布日期、精确测试数量或不存在的验收结论。当前版本的最终安装包和实际测试范围以 [验证记录](VERIFICATION.md) 与 构建记录（`artifacts/build-info.json`） 为准。

## 0.6.2 — 2026-11-22

macOS 新增全局截屏翻译。默认按 `⌘⇧2` 框选，可在设置中更换或关闭快捷键。截屏需要 macOS 录屏权限，拖动确认后的选区使用已有的图片翻译流程。

## 0.6.0 — 2026-10-23

新增独立“双向对话”工作区，客户外语自动译成中文，我的中文自动译给客户。客户语言可固定或自动跟随最近实际外语；未收到外语前中文默认译成英语。固定客户语言时收到第三语言，按该语言译成中文，但不覆盖之后中文回复的客户目标语言。每条自动消息先做一次固定 Flash 语言分类，纯数字/标点/emoji 本地回退；无法确定时明确显示沿上一次方向，用户可手动选择译成中文或译给客户。

语言检测长文最多取首、中、尾各 4,000 Unicode 字符，分类采样不截断翻译原文。文字通常产生三次 API 请求；自动路由图片/截图通常五次。人工方向不调用检测；已完成 OCR 和语言路由后的翻译失败重试复用原结果，不重复执行前置阶段。提问、命令和图片文字仍作为待译数据，不生成客户回复或执行操作。

模式、客户语言和最近方向按会话持久保存，历史标记模式并在打开时恢复。标准/双向草稿和附件独立，关闭历史保存时也能在本进程切换恢复每模式最近一份时间线；完全退出仍不恢复未保存数据。全局重置覆盖非活动会话和缓存，清空历史不会因模式切回而复活。双向参考允许同客户、同语言对的反向已校验译文先交换原文/译文再对齐，保留 12 对/24,000 字符预算，不混入第三语言、其他客户或未校验编辑。

加入安全的段落、标题、列表和代码显示，译文主体更易阅读，原文次要展开；HTML 和文本中的链接不执行、不自动加载。后端五类模型输出显式要求顶层 JSON object，拒绝 serde 可能接受的 positional arrays。记忆协议仍为 v2，SQLite schema 仍为 2，新模式数据通过 metadata 兼容旧库。

本版实际测试与交付结果见 [验证记录](VERIFICATION.md) 和 构建记录（`artifacts/build-info.json`），完整实现说明见 [开发手册第 19 节](DEVELOPMENT.md#19-自动双向对话模式)。

安装包：Moyu 0.6.0（`artifacts/Moyu-0.6.0-windows-x64-setup.exe`）。验证报告归档：`artifacts/releases/0.6.0/`。

## 0.5.0 — 2026-10-20

新增 Windows 全局截屏翻译。默认 `Ctrl+Alt+T`，可在设置页直接按键自定义、恢复默认或停用；输入框也提供截屏按钮。应用在托盘运行时仍可触发，完全退出后释放热键。占用冲突提示明确，修改失败保留原组合；录入过程中暂停旧快捷键，失焦后恢复。

框选界面使用本机 Windows 原生窗口，支持反向拖动、虚拟桌面负坐标和物理像素选区。松开自动识别翻译，Esc/右键可取消。整屏快照只用于本地框选，最终仅选区 PNG 进入图片流程；不修改剪贴板。截图作为独立顺序任务，不混入已有草稿或上传附件，翻译忙时排队，失败可重试或移除。

沿用 0.4.0 的图片 OCR/复核与文字翻译/审核、完整会话历史和长文恢复。热键保存在 metadata，schema 仍为版本 2。补齐完整 [开发与维护手册](DEVELOPMENT.md)，记录文件职责、IPC、存储、并发、模型协议、测试和发布步骤，明确已实现边界与后续维护方向。

安装包：Moyu 0.5.0（`artifacts/Moyu-0.5.0-windows-x64-setup.exe`）。本版验收报告另存于 `artifacts/releases/0.5.0/`。

## 0.4.0 — 2026-10-20

补齐完整翻译会话历史：按会话每页 40 份浏览，搜索任意原文或译文，打开后回看完整时间线并继续翻译，可删除单份会话或清空历史。取消超过 1,000 条历史自动清理，保留模型最近 12 对/24,000 字符参考范围。各会话持久保存独立上下文重置点；全局配置、术语和记忆变更不会在重新打开后复活旧参考。历史插入增加持久递增序号，修复删除最新记录后 rowid 复用影响重置边界的问题。

新增 PNG/JPEG/WebP/GIF 上传和剪贴板图片粘贴，包括有效 MIME 但没有扩展名的图片。Flash 识别可见文字并图像核对，再由所选模型生成和审核文本译文。OCR 失败保留附件；翻译失败重试复用识别文字，不重复 OCR；新草稿和后续附件与执行中任务隔离。历史保存缩略图、识别文字和译文，不保存原图。

SQLite schema 从 1 迁移到 2，history 增加可空 source_image，迁移保留旧记录。该版验证记录为 33 项后端、29 项界面、3 项布局通过，并单独完成一张合成英文 PNG 的四次真实 DeepSeek 调用；此范围不等于所有语言和注入场景均已通过。后续 artifacts 报告会由新版本刷新，历史结果以本段和保留发布记录辨别。

归档安装包：Moyu 0.4.0（`artifacts/Moyu-0.4.0-windows-x64-setup.exe`）。

## 0.3.0

取消整篇 6,000 字符提交门槛，加入本地长文规划、按顺序自动分段翻译、暂停/继续、失败重试与取回未译原文。分段完整保留原文与空白，预算采用 UTF-8 字节的保守估算，不标为官方精确 tokenizer。自动长文批次内保持相邻段上下文，即使跨次连续上下文关闭。

加入 Windows 托盘：关闭主窗口收起并保持进程运行，点击图标或菜单恢复，选择“退出墨译”才结束。已记录的原生隐藏测试只证明对应专用测试实例隐藏后进程继续运行，不能替代之后所有版本的托盘复测。

归档安装包：Moyu 0.3.0（`artifacts/Moyu-0.3.0-windows-x64-setup.exe`）。
