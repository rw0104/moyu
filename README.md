# 墨译 · Moyu

Windows 和 macOS 桌面翻译软件，使用 Tauri 2 + React 19 + TypeScript + Rust。支持文字与图片文字翻译，DeepSeek 负责识别、翻译与一致性检查，本地 SQLite 保存完整会话、术语、确认译文和偏好。

## 使用

macOS 13 及以上可从 [GitHub Releases](https://github.com/rw0104/moyu/releases) 下载通用 DMG。打开后将「墨译 Moyu」拖入「应用程序」。从 0.6.1 起，点击「收起到托盘」或窗口左上角红色关闭按钮后，单击 Dock 或顶部菜单栏里的墨译图标即可回到原窗口。0.6.0 用户也可以右键点击菜单栏图标，选择「显示主窗口」。

0.6.0 新增独立双向对话：外语来信译成中文，中文回复自动跟随客户语言，并优化原文/译文排版。可按[本地开发说明](#本地开发)生成 Windows x64 安装包。版本测试结果见[验证记录](docs/VERIFICATION.md)。

安装后打开「设置」，填入自己的 DeepSeek API Key。Mac 使用系统钥匙串保存密钥，Windows 使用凭据管理器。

- 外语 → 中文：源语言选「自动检测」，目标语言选「简体中文」。
- 中文 → 外语：源语言选中文，目标语言选择英语、日语等。支持 12 种目标语言。
- 点击翻译或按 `Ctrl+Enter`。显示前会完成生成与一致性检查，通常产生两次 API 请求。
- 图片翻译：点击输入框的图片按钮，或在输入框内按 `Ctrl+V` 粘贴截图，每次处理一张。支持 PNG、JPEG、WebP、GIF，最大 32 MiB，每边最多 8,192 像素。
- **截屏翻译**。macOS 0.6.2 起默认按 `⌘⇧2`（Command + Shift + 2），Windows 默认按 `Ctrl+Alt+T`。也可以点击输入框的截屏按钮。拖动框选，松开后识别并翻译；按 `Esc` 取消。
- **Mac 首次使用**。在「系统设置 → 隐私与安全性 → 录屏与系统录音」（旧版 macOS 称为「屏幕录制」）中允许「墨译 Moyu」访问屏幕。如果系统提示重新打开应用，按提示操作，再次按快捷键。
- 在「设置 → 截屏翻译」按下新组合并保存，也可恢复默认或停用。Mac 支持 Command、Control、Option 搭配字母、数字或 F1–F20，可加 Shift。Windows 至少需要 Ctrl 或 Alt。快捷键冲突时会提示；收起主窗口后，全局快捷键仍可使用。
- 截屏会独立翻译，不混入已有草稿或附件；已有翻译忙时先排队。取消框选不会调用模型。框选只在本机处理，不修改剪贴板；只有最终选中的区域会进入图片翻译流程并发送到 DeepSeek。
- 顶部使用单行工具栏；点击“上下文”可查看模型参考范围和当前材料条数。输入框空闲时保持紧凑，输入多行内容时自动增长，清空后收回。
- 直接粘贴完整长文，软件不再用 6,000 字符阻止提交。长文按输出预算自动规划，优先在段落、句子边界分段，原文字符和换行完整保留。分段采用保守的字节估算，不是假称精确计算的官方 tokenizer。
- 长文队列逐段翻译并显示进度，可在当前段完成后暂停，再从下一段继续；失败时只重试未完成部分，也可取回未译原文。等待期间可准备下一份草稿。队列本身保存在当前窗口进程，托盘收起后继续；主动退出应用后未译队列不会恢复。
- 本地分段不调用模型。每个内容片段通常需要生成、审核两次请求；模型输出不完整时会进一步拆分重试，可能增加调用次数。
- 同一篇长文的自动分段始终接续批次上下文；关闭连续上下文时，批次完成后的独立请求仍不参考前文。
- 点击“收起到托盘”或关闭主窗口，软件进入 Windows 右下角系统托盘。点击托盘图标或菜单“显示主窗口”恢复，选择“退出墨译”才结束应用；不添加开机启动。
- 连续翻译：发送后追加一组原文/译文，可继续输入下一段。模型参考同一材料最近最多 12 组、相同方向和风格的译文（双向模式会把同语言对的反向消息对齐后参考）。换材料时点击「新建上下文」。
- 长文阅读：原文与很长的译文可展开；时间线分批显示最近 40 段，可加载更早记录。阅读旧段落时不会自动跳到底部，点击「回到最新」继续。
- 会话历史：在「历史记录」搜索任意原文或译文，每页显示 40 份会话。打开后可回看完整时间线并接着翻译；也可删除整份会话。打开会话时，会恢复该会话重置点之后、预算内的模型上下文。
- 长期记忆：逐段修改或确认译文后点击「校验并记住」。软件按当前术语重新审核这对原文/译文，审核通过才进入记忆；确认操作产生一次 API 请求，即使普通翻译暂时关闭记忆参考也会在确认时校验适用术语。
- 术语库：录入希望固定使用的术语对，按源语言和目标语言区分。修改术语会重置所有会话的模型上下文，旧版本精确记忆不再命中；已保存的对话仍可回看。

当前模型可选 `deepseek-flash` / `deepseek-v4-pro`，对应 [DeepSeek 当前官方模型](https://api-docs.deepseek.com/quick_start/pricing/)。接口固定到 DeepSeek 官方 HTTPS 地址。

## 双向对话怎么用

在侧栏选择「双向对话」，客户语言默认「自动跟随」。中文消息自动译给客户，外语消息自动译成简体中文；还没收到外语时，中文默认译成英语。收到德语后，之后中文回复会跟随为德语；法语、西班牙语、日语等当前支持语言也一样。

同一客户使用同一份对话，不同客户点击「新建上下文」。客户语言和最近识别方向按会话保存，历史打开时会恢复模式。也可以固定客户语言；遇到第三语言来信仍能译成中文，但不会改变已固定的回复语言。

普通翻译与双向对话的草稿、附件和记录分别保留，切回可以继续。已校验的同一客户、同一语言对的双向消息会对齐为当前方向的参考，最多最近 12 组、24,000 字符；不会因为换了方向就丢掉全部前文，也不会把其他客户或第三语言加入这次参考。

自动消息会先用 DeepSeek Flash 分类语言，再生成并审核译文，普通文字通常三次请求，带图片或截图通常五次。只在提交时分类，不在每次键入时联网；长文分类最多采样首/中/尾合计 12,000 个 Unicode 字符，实际翻译仍保留全文。纯数字、表情或无法可靠识别的短句沿用会话方向并明确提示，可用「对话翻译方向」为当前条消息纠正；人工选方向不调用分类。翻译失败重试复用已经确定的方向。

对话显示区分「客户消息」与「我的消息」，译文作为阅读主体，原文按需展开；段落、列表、标题和代码以安全文本布局显示，原始译文仍可完整复制。它仍是翻译模式，不会自动回复客户、承诺价格、库存或交期。实际验证范围见 [发布验证](docs/VERIFICATION.md)。

## 图片怎么翻译

图片先由固定的 DeepSeek Flash 识别可见文字，再用另一次图像请求核对识别结果。通过后，识别文字进入普通翻译流程，由当前选定的模型生成并审核译文。因此，一张未命中记忆、无需分段的图片通常产生四次 API 请求；长文本分段、重试和记忆复用会改变调用次数。

图片中的问题或命令只作为待识别、待翻译的内容处理。软件展示图片缩略图、识别原文和文本译文，不在原图内替换文字。识别失败时附件仍留在输入框，便于重试或更换图片；识别成功后重试翻译会复用已识别文字，不重复 OCR。

原图仅在本次处理的进程内存中暂存，并发送至 DeepSeek 完成识别和图像复核，不写入历史数据库。开启历史保存时，只保存宽不超过 240、高不超过 180 像素的 PNG 缩略图、识别文字、译文及图片名称等信息，**这些本地记录未加密**。

## 记忆的具体行为

已确认的译文只有原文、翻译方向、风格、模型、术语版本与提示词版本都相同时，才可直接复用。在已有连续上下文时，软件重新请求模型，以免复用脱离语境的旧译文。相同配置下的精确记忆可离线使用。历史记录不会自动提取指令，也不会自动变成永久偏好。

可见的完整时间线与发送给模型的上下文是两个范围。模型每次最多参考最近 12 对原文/译文，总参考长度最多 24,000 个 Unicode 字符，按连续的最近片段选择，更早记录仍可回看。这属于辅助参考，不能替代整篇文档翻译。开启历史时可跨软件重启恢复当前材料；关闭历史后的新增记录只保存在本次软件进程内。关闭连续上下文也可以保留本次运行内的时间线。

各会话分别保存模型上下文重置点，打开旧会话时仍遵守其重置点。手动重置只影响当前会话。切换模型、记忆/上下文/历史开关，编辑术语，或删除、清空翻译记忆，会持久重置所有会话的模型参考范围，保留已保存的对话。重启或重新打开会话不会把重置前的历史重新加入模型参考。「新建上下文」开启一份空白材料；清空历史还会清空当前时间线。

保存的历史和当前材料的对话时间线不再设 1,000 条上限，也不自动过期清理；历史页按会话每页 40 份浏览，时间线按每批 40 段展开。翻译记忆列表仍显示最近 500 条。可删除整份会话或清空全部历史，记忆可逐条删除或清空。升级会迁移现有数据库并保留其中的记录。用户编辑稿不会自动覆盖用于模型参考的已校验原结果。

## 数据与限制

原文、当前命中的术语及选中的上下文会发送到 DeepSeek；一致性检查还会发送候选译文。图片识别和图像复核都会发送原图，翻译与译文审核只使用识别文字及相关翻译数据。软件没有遥测、模型工具调用、网页读取或命令执行功能。正常联网翻译、图片识别和确认记忆需要有效密钥、网络和 DeepSeek 账户余额。

本地数据库位于 `%APPDATA%\com.moyu.translate\moyu.sqlite3`（实际位置以设置页为准），**历史、术语和记忆未加密**。不保存历史开关不会删除此前保存的记录；需要时请手动清空。移除 API Key 不影响本地记录。

固定提示词、严格 JSON、禁止工具、完整响应检查和第二次模型审核用于降低越界风险。格式错误、工具调用、截断和未通过审核的候选不会显示或写入历史。**大模型及同模型审核不能保证 100% 语义不越界**，用户确认的记忆和术语也可能存在错误。完整边界见 [安全说明](docs/SECURITY.md)。

## 本地开发

依赖 Node.js 22.12+、Rust 1.88+，以及 [Tauri Windows 前置依赖](https://v2.tauri.app/start/prerequisites/)：Microsoft C++ Build Tools 与 WebView2。本次使用 Node.js 24.16、Rust 1.92 构建。

```powershell
npm ci
npm run tauri dev
```

浏览器预览：`npm run dev`。浏览器模式只展示界面，不保存密钥、不调用模型，不提供虚构译文。真实功能在桌面模式运行。

```powershell
npm run build
npm test
npm run tauri build
```

Windows 安装包在 `src-tauri/target/release/bundle/nsis/`。这是本机未签名构建，尚未配置代码签名证书。使用 `npm run tauri build -- --no-bundle` 可仅构建可执行文件。

完成构建且 `artifacts/` 中已有本版本的验收报告时，可运行 `python scripts/package-artifact.py`，核对内嵌界面资源，再复制安装包并生成 SHA-256 记录。安装包与验收产物保存在本地。

`package-lock.json` 与 `src-tauri/Cargo.lock` 固定本次依赖解析版本。新模型上线时需同步更新前后端模型白名单，并检查官方接口兼容性。
